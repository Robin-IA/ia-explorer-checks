## What a pass means

Each check combines automated tools with a review of the code and pages against a written checklist. A pass means neither found anything open on the date and commit above. It is not a formal WCAG conformance claim. Automated testing finds a minority of accessibility barriers. Testing with people who use assistive technology is still worth doing, and a change to the explorer needs a re-run.

## Code validity

### `V-2bceb0` HTML parse error: expected doctype but got start tag

- **Must fix** · found by html5lib
- **Where:** `mockup/index.html:1`

```text
<title>The Federal Pandemic Record</title>
```

**Recommended fix:** Add <!doctype html> as the very first line. Without it the page renders in quirks mode, which changes layout and box sizing.

document.getElementById("pages").innerHTML = M.pages.map(p => {

## Accessibility (WCAG 2.2 AA)

### `A-9f5c12` Elements must meet minimum color contrast ratio thresholds

- **Must fix** · found by axe-core 4.10.3 · WCAG 1.4.3
- **Where:** `/mockup/ color-contrast`

```text
1 element(s): .mock
Fix any of the following:
  Element has insufficient color contrast of 4.12 (foreground color: #a86a12, background color: #f5f7f9, font size: 9.0pt (12px), font weight: normal). Expected contrast ratio of 4.5:1
```

**Recommended fix:** Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds See https://dequeuniversity.com/rules/axe/4.10/color-contrast?application=axeAPI

### `A-3cf883` <html> element must have a lang attribute

- **Must fix** · found by axe-core 4.10.3 · WCAG 3.1.1
- **Where:** `/mockup/ html-has-lang`

```text
1 element(s): html
Fix any of the following:
  The <html> element does not have a lang attribute
```

**Recommended fix:** Ensure every HTML document has a lang attribute See https://dequeuniversity.com/rules/axe/4.10/html-has-lang?application=axeAPI

### `A-b6a5a7` No main landmark or skip link

- **Must fix** · found by review · WCAG 2.4.1
- **Where:** `mockup/index.html:127`

```text
There is a <header> and a <nav>, but the views are not inside <main>, so a screen reader user cannot jump past the masthead.
```

**Recommended fix:** Wrap the four view sections in <main id="main">. Optionally add <a class="skip" href="#main">Skip to content</a> as the first element of <body>, visible on focus. This also clears the landmark-one-main and region advisories.

### `A-55ed4f` Search box has no visible label

- **Must fix** · found by review · WCAG 3.3.2
- **Where:** `mockup/index.html:148`

```text
Only placeholder text and aria-label; the placeholder disappears once typing starts.
```

**Recommended fix:** Add <label for="q">Search titles</label> above the input (it may be visually small) and drop the aria-label it duplicates.

### `A-79ad07` Result count changes are not announced

- **Must fix** · found by review · WCAG 4.1.3
- **Where:** `mockup/index.html:149`

```text
<span id="count"> is rewritten on every filter and search change but has no live region.
```

**Recommended fix:** Change it to <span id="count" role="status"></span>. Screen readers then announce "N of M documents" after each change without moving focus.

### `A-c9be60` Ticking a facet throws keyboard focus to the top of the page

- **Must fix** · found by review · WCAG 2.4.3
- **Where:** `mockup/index.html:213`

```text
The change handler calls render(), which replaces #facets via innerHTML, destroying the focused checkbox.
```

**Recommended fix:** In the change handler, record document.activeElement.id before render() and call document.getElementById(id)?.focus() after it. The checkbox ids (f-<key>-<value>) are already stable.

### `A-6f1b56` Month filter on the histogram works by mouse only

- **Must fix** · found by review · WCAG 2.1.1
- **Where:** `mockup/index.html:234`

```text
svg.querySelectorAll(".bar").forEach(b => b.onclick = ...) — the bars are SVG rects with no tabindex or key handler.
```

**Recommended fix:** In renderHist, give each .bar tabindex="0", role="button", aria-pressed reflecting st.month, and an aria-label such as "March 2020: 412 documents". Handle Enter and Space in a keydown listener that calls the same toggle as the click. A <select> of months next to the chart works too.
